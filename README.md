# Aplicação Web — Projeto Acadêmico

Este repositório contém o código-fonte de um projeto desenvolvido durante a graduação em Análise e Desenvolvimento de Sistemas (ADS). O objetivo principal foi construir uma solução funcional integrando ferramentas modernas de apoio ao desenvolvimento, IA generativa e versionamento de código.

---

### **Estrutura & Metodologia de Desenvolvimento**

Para otimizar o tempo de entrega e a construção da interface e funcionalidades, utilizei um fluxo de desenvolvimento híbrido apoiado por ferramentas no-code/low-code e assistentes de código com IA:

* **Desenvolvimento Base (Lovable):** Utilizado como plataforma principal para prototipagem rápida, estruturação inicial das telas e lógica central da aplicação.
* **Continuidade & Refatoração (Cursor, GitHub Copilot & Claude):** À medida que o projeto avançava e demandava personalizações mais complexas (ou ao atingir os limites da plataforma base), utilizei IDEs com IA integrada para depurar código, escrever métodos específicos e refatorar trechos vitais da aplicação.
* **Gestão de Versão & Fluxo Git (Terminal):** Controle total do código-fonte via linha de comando (terminal Linux/Bash). Utilizei comandos do Git para clonar repositórios, gerenciar branches e migrar o projeto entre diferentes ambientes/contas sem perder o histórico de alterações.

---

### **Ferramentas e Tecnologias Utilizadas**

* **Assistentes de IA & Low-Code:** Lovable, Cursor, GitHub Copilot, Claude AI
* **Controle de Versão:** Git, GitHub, Terminal (CLI)
* **Linguagens & Ecossistema:** TypeScript / JavaScript / HTML / CSS

---

### **Aprendizados Práticos**

* Resolução de problemas reais de ambiente e migração de código via terminal.
* Integração de múltiplos assistentes de IA no ciclo de vida de desenvolvimento de software.
* Gestão de dependências e fluxo de trabalho acelerado focado em entregáveis funcionais.
